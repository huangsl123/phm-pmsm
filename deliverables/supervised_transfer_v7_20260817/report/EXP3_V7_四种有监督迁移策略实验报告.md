# EXP3 V7 四种有监督迁移策略实验报告

## 1. 实验目的与性质

V7在V3/V4思路上重新实现并严格区分四种抗遗忘策略：标准LwF、知识蒸馏（Distill）、
EWC和经验回放。任务为1.0 kW源域到3.0 kW目标域的15类跨功率迁移。

本实验是**有监督迁移学习**：四种策略的适应阶段均使用3.0 kW目标训练集的真实类别标签
`y_t`计算目标域交叉熵。因此，V7不是无监督迁移，也不是半监督迁移。源域和目标域使用同一个
376→512→256→15网络、同一个分类头和同一份模型参数，不使用双专家或按域切换分类器。

## 2. 数据与评估协议

- 类别数：15类，1.0 kW与3.0 kW采用同一物理故障映射；
- 输入：从重新解析的原始记录NPY中按8192点窗口提取376维无量纲统计、频域和序分量特征；
- 划分：按每条原始记录的时间区域隔离，训练/测试/验证为70%/20%/10%；
- 标准化：仅使用两域训练输入估计均值和标准差，不使用验证集或测试集；
- 随机种子：42和123；每个方法3组参数，共24次训练；
- 配置选择：每个epoch同时计算源域和目标域验证集，先最大化两域准确率的较小值，再比较均值；
- 测试纪律：每个方法只测试由验证集锁定的配置，测试集不参与梯度、早停或调参；
- 误差表示：表中“±”为两个随机种子的样本标准差，不是单次预测的不确定度。

当前源数据每个功率、每个类别仅有一条长记录，因此时间块隔离只能防止窗口直接重叠，不能替代
跨独立采集批次或跨电机泛化验证。这是全部数值必须附带说明的数据限制。

## 3. 四种策略的标准实现

设源域预训练模型为冻结教师 `f_old`，当前共享模型为 `f`，目标真实标签交叉熵为
`L_t = CE(f(x_t), y_t)`。

### 3.1 LwF

标准的无样本回放LwF只在目标输入上训练：

`L = (1-α)L_t + α T² KL(softmax(f_old(x_t)/T) || softmax(f(x_t)/T))`

LwF不读取源域样本，也不计算源域硬标签损失。它要求旧教师在新域输入上的软输出具有可用意义。

### 3.2 Distill

为与LwF和硬标签经验回放严格分开，V7中的Distill定义为“源记忆样本上的软标签蒸馏”：

`L = L_t + β T² KL(softmax(f_old(x_s)/T) || softmax(f(x_s)/T))`

它读取源域训练输入，但不读取源样本硬标签；旧知识来自教师软分布。这个实现属于有源样本记忆的
知识蒸馏，不应表述为无样本LwF。

### 3.3 EWC

`L = L_t + λ/2 Σ_i F_i(θ_i-θ_i*)²`

`F_i`由源域**训练集**逐样本负对数似然梯度平方的均值估计，batch size为1。验证集不进入Fisher
估计，避免此前用批均值梯度近似、混入验证数据或尺度错误的问题。

### 3.4 经验回放

`L = L_t + γ CE(f(x_s), y_s)`

经验回放同时使用目标域标注批次和源域标注批次，直接用源硬标签保持旧任务性能；不使用教师模型。
“回放”是联合训练损失，并不是把源样本伪装成目标样本，也没有改变样本的域归属。

## 4. 相比V3/V4的关键修正

- 四个策略具有互斥、可核查的损失分支，不再把LwF、蒸馏和经验回放混写；
- LwF为目标输入上的教师约束且无源样本，Distill为源记忆上的软教师约束；
- EWC使用源训练集逐样本经验Fisher，验证集不参与Fisher计算；
- 所有策略都显式包含目标域真实标签交叉熵，方法性质统一标为有监督迁移；
- 使用一个共享模型和共享15类头，两域结果来自同一状态字典；
- checkpoint按双域验证下界锁定，而不是只追求目标域或使用测试集挑模型；
- 每个配置保存源/目标各自的train/validation loss和accuracy四宫格（共8条曲线）、双域混淆矩阵与模型。

## 7. 结果分析

1. Distill取得最高源域均值，Replay取得最高目标域均值和最高双域最低值；两者均稳定超过80%。
2. EWC修正后两域均超过70%，但对旧参数的强约束使源域仅约72.55%，平衡性弱于Distill和Replay。
3. 标准LwF未达到双域70%。原因不是实现中缺少目标标签，而是源教师直接作用于3.0 kW目标输入时，
   教师的跨功率软输出不可靠；α过大时尤其明显，目标验证准确率降至11.54%。
4. Distill把教师约束放回其可信的1.0 kW源样本，同时用真实3.0 kW标签学习目标任务，因而显著优于LwF。
5. Replay效果最均衡，说明在当前数据规模下，保留源硬标签监督比只约束参数或在目标输入上模仿教师更有效。

## 8. 结论

V7确认四种方法都是有监督迁移策略，但保留旧知识的机制不同。推荐主结果使用Replay γ=1.0；若论文
强调教师—学生知识保持，可报告Distill β=0.2。EWC可作为正则化基线。LwF应作为真实负结果保留，
不能为了达到阈值而改成双模型、切换分类头或借用测试集选参。
