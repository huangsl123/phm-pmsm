**实验系列**: 跨功率故障诊断迁移学习

**任务**: 1.0kW → 3.0kW 跨域迁移学习

### 1.3 EXP2: 跨域无适应实验 (2026-05-25)

**实验目的**: 验证跨功率域的性能差异
